# 历史旧稿归档

此目录保存项目早期的 MySQL、DevOps、Jenkins 和缓存笔记，仅用于追溯历史内容，**不会发布到文档网站**。

当前唯一发布源是 [`src/content/docs/`](../src/content/docs/)。新文章和现有主题更新都应直接在发布源中完成，不要继续向本目录增加内容。

## 当前内容

- `mysql/performance/`：早期 MySQL 性能与存储引擎草稿，部分结论、版本和工具已经过时。
- `devops/theory/`：早期 DevOps 概念笔记，尚未形成当前站点所要求的可验证实践路径。
- `devops/tools/`：Jenkins 等工具草稿，与仓库中的历史 Jenkins 静态文件相关。
- `xcache.md`：旧缓存主题草稿。

这些文件没有 Starlight Frontmatter，不受站点侧边栏、链接和构建完整性检查保护。

## 迁移规则

旧稿仍有价值时，按以下流程迁移：

1. 确认内容属于哪个现有一级主题。
2. 对照目标软件当前版本重新验证结论、命令和配置。
3. 按 [`CONTRIBUTING.md`](../CONTRIBUTING.md) 重写为独立、可验证的文章。
4. 加入主题 `index.md` 和 `astro.config.mjs` 侧边栏。
5. 完成全站构建与链接检查。
6. 确认发布版本覆盖旧稿有效信息后，再单独处理旧文件。

不要为了减少文件数量直接删除本目录，也不要把未经复核的旧稿批量复制到发布目录。
